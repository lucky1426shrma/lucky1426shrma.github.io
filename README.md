# Lucky Sharma — Portfolio

> Personal portfolio built with React 18, TypeScript, Tailwind CSS, and Vite.

Live site: [lucky1426shrma.github.io](https://lucky1426shrma.github.io/)

## Overview
- **Systems & Agentic AI Projects**: Multi-Tier Caching Reverse Proxy & Cloud Deployment Engine, Eval-Driven Video Transcript RAG Application, Adaptive MCP Enterprise Agent (Razorpay Buildathon), Shaharnaama, Upsolvers.
- **Competitive Programming**: LeetCode Knight (Rating 1974, Top 2.9%), Codeforces Specialist (1449), CodeChef 3-Star (1617), ICPC India Prelims.
- **Interactive Spider-Man Canvas**: Real-time particle physics, Spider-Sense radar pulses, dynamic lens tracking with periodic squinting and Web Audio sound synthesis.
- **Design System**: Editorial slate `#0d1117` aesthetic with Geist and Geist Mono typography.

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide React
- **Build Tool**: Vite 5
- **Deployment**: GitHub Pages & GitHub Actions CI/CD

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
```
